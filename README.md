# Famijote (nom de travail)
*La cuisine se partage en famille.*

Application de cuisine familiale : carnet privé de recettes, planification des repas, courses et cuisine guidée. La version historique est une PWA HTML/CSS/JavaScript publiée sur [GitHub Pages](https://miriatha.github.io/livre-recettes-pwa/).
